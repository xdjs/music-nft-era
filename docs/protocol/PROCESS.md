# Actual process and reproducible method

1. **Inspect context and boundaries.** Read applicable project instructions, existing screens and the meeting brief. Use the private November 3 record only for intent; its speaker labels do not establish individual authorship. Keep this standalone and preserve dirty workspaces. Locate the owning issue before repository work.
2. **Observe reference experiences.** Record the actual interface inspected, viewport, interaction, evidence and weakness. Separate visited behavior from a search result or promotional image. Translate the lesson into a design decision; do not copy identity or assets. See the reference matrix in `docs/RESEARCH.md`.
3. **Build an evidence ledger.** Store original URL, author, publication/event date, claim supported, evidence type and limitation. Research independently of the supplied roster, then investigate named gaps. Fetch original public documents where possible. Private Docs must not go through public scraping services.
4. **Follow artifacts and credits.** A source can identify a release, which supplies contributors, which leads to another credited work. Ownership supplies transaction evidence only. Retain alternate names and conflicting counts. A release announcement is not an outcome.
5. **Write a complete thought before arranging a scene.** Establish the artist's stakes; explain the mechanism through an actual work; show what people did; leave a route into more detail. The current frame follows changing participation rather than a sequence of platform funding rounds.
6. **Compose the documentary.** Use the existing approved visual system, full-frame photography, contained original artworks, varied passage positions and native-scroll crossfades. Keep evidence and longer branches optional. Use real captions so a portrait never masquerades as an event photograph.
7. **Connect listening.** Verify an allowlisted contract/token using the read-only adapter, read metadata and follow original media. Use a play control on artwork and a persistent queue. Cached artwork derivatives are for display; do not replace the original recording with an unverified reupload.
8. **Connect people.** A canonical profile can have historical aliases, a brief source-backed introduction, release credits, related moments and verified external links. Names in editorial text open the existing drawer. Unknown biography is a gap, not an invitation to invent influence. Metadata-derived collaborator records are labeled as credits.
9. **Run behavioral checks and inspect the result.** Validate references and security boundaries, then browser navigation, focus, reduced motion, themes, queue and failures. Inspect captures rather than equating a passing test with aesthetic acceptance. Keep live-media availability distinct from controlled tests.
10. **Package the knowledge.** Record decisions, source paths, prompts, reproduction commands and remaining dependencies. Update the Lab submission packet; do not publish merely because the packet exists.

The workflow used repository reads and edits, public web research, Firecrawl source retrieval, Grok interviews through the user's browser, Ethereum metadata reads, image asset conversion, and Playwright verification. Tool vendors are replaceable; their evidentiary roles are not. Public research caches are disposable; curated sources and the distinctions they support must remain tracked.
